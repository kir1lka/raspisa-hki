# Журнал посещаемости

Первый раздел в `/dashboard`. Вход — существующей учётной записью администратора или преподавателя. После обновления приложения потребуется войти заново для создания серверной сессии. Оба типа пользователей имеют доступ к журналам всех групп.

- Выберите группу и месяц. Колонки создаются из обычных занятий расписания; мероприятия не включаются. Можно отфильтровать предмет; выбранный предмет сохраняется при переходе между группами. Для обновления после редактирования расписания нажмите «Обновить».
- Еженедельные занятия исключаются в праздники и каникулы из настроек. Занятие с конкретной датой считается явным исключением и отображается в эту дату.
- «Список учеников» позволяет вставить до 100 имён за раз, каждое с новой строки. Нажатие на имя открывает исправление имени и архивирование. Архивных учеников можно показать и вернуть.
- В ячейке выбираются Н (отсутствовал), П (присутствовал), У (уважительная причина), Б (болеет), оценка 2–5 или пустая отметка. Изменение сохраняется сразу; ошибка показывается без изменения отображаемой отметки.
- «Отчёт в Excel» формирует файл за выбранный период: текущую группу, одну указанную группу или все группы. Каждая группа находится на отдельном листе. Вертикальной прокрутки внутри журнала нет: таблица увеличивает страницу вниз, а для дат остаётся горизонтальная прокрутка.
- Записи хранятся в `attendance_student` и `attendance_mark` существующей БД; схема создаётся стандартным `ddl-auto=update`. Отмеченные занятия остаются видны после удаления занятия из расписания. Удаление группы с журналом запрещено.
- Колонки без отметок всегда отражают текущее расписание, это не архив всех предыдущих версий расписания. Два занятия в один день имеют отдельные колонки.
- API `/api/attendance` требует серверную сессию; изменения — заголовок `X-Attendance-Request: 1`. Ответы журнала не кешируются браузером или service worker.

Проверки: `./gradlew test` и `npm run build --prefix frontend`. Интеграционные тесты журнала используют отдельную H2 в памяти и не меняют рабочую БД.

Удаление ученика: нажмите на имя → «Удалить ученика» → подтвердите удаление вместе с отметками. Операция удаляет ученика и все его отметки за все месяцы; архив остаётся вариантом для сохранения истории.
